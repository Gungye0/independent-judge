# 평가 보고서 템플릿

아래 형식을 그대로 채웁니다. `{ }` 부분만 바꿉니다.

```markdown
# 독립 평가 보고서

- 평가 대상: {결과물 경로 또는 이름}
- 요구사항 출처: {요구사항 경로 또는 "사용자 원문"}
- 제외한 입력: {없음 | 대화 기록, 작성자 설명 등}

## 체크리스트

| # | 요구사항 항목 | 요구사항 원문 | 판정 | 근거 (결과물 인용) | 부족한 부분 |
|---|---|---|---|---|---|
| 1 | {조건 하나} | "{원문 구절}" | 충족 | `{파일:줄}` "{인용}" | - |
| 2 | {조건 하나} (암묵) | "{원문 구절}" | 부분 충족 | `{파일:줄}` "{인용}" | {빠진 것} |
| 3 | {조건 하나} | "{원문 구절}" | 미충족 | 없음. 찾아본 곳: {위치} | {빠진 것} |

## 집계

충족 {n} / 부분 충족 {n} / 미충족 {n} (전체 {n})

## 수정이 필요한 항목 (우선순위 순)

1. [P1] #{번호} {무엇이 부족한지}
2. [P2] #{번호} {무엇이 부족한지}
3. [P3] #{번호} {무엇이 부족한지}

## 참고 의견 (판정에 반영하지 않음)

- {선택 사항. 없으면 "없음"}
```

## 판정 기준 요약

| 판정 | 조건 |
|---|---|
| 충족 | 인용한 근거가 조건 전체를 직접 보여줌 |
| 부분 충족 | 조건의 일부만 보여주거나, 근거가 간접적임 |
| 미충족 | 근거 없음, 또는 조건과 반대 |

| 우선순위 | 조건 |
|---|---|
| P1 | 핵심 목적 또는 명시적 금지 조건 위반 |
| P2 | 명시된 요구사항 누락 |
| P3 | 형식, 표현, 사소한 누락 |
